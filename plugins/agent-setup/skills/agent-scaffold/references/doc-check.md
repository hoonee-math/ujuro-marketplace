# 문서 대조 절차

코딩 에이전트 하나의 설정 템플릿이 그 에이전트의 현재 공식 문서와 맞는지 대조한다. 파일을 고치지 않고 보고만 한다.

## 받는 것

- 대상 에이전트 이름
- 템플릿이 만든 파일 목록과, 파일마다 설명·문서 주소, 설정 파일이면 키별 설명·문서 주소

## 하는 일

1. 받은 문서 주소를 연다. 주소가 옮겨졌으면 제작사 문서 사이트의 색인(`llms.txt`, 사이트맵, 목차)에서 다시 찾는다. 제작사 공식 문서만 근거로 쓰고, 블로그·커뮤니티 글은 쓰지 않는다.
2. 항목마다 문서와 대조한다.
   - 파일·폴더 — 그 위치와 이름을 지금도 쓰는가, 다른 것으로 대체됐는가
   - 형식과 키 — 이름·구조가 달라졌는가, 없어진 키가 있는가
   - 설명 — 템플릿의 설명이 문서 내용과 다른가
   - 버전 관리 — 문서가 커밋하라는 것, 제외하라는 것과 맞는가
3. 템플릿에는 없지만 문서가 새 프로젝트에 권장하는 것이 있으면 따로 적는다.

## 보고

기억으로 판단하지 않는다. 문서에서 확인한 것만 적고, 차이마다 근거 문서 주소를 붙인다.

- **달라진 것** — 항목, 템플릿의 내용, 문서의 내용, 근거 주소
- **새로 권장되는 것** — 내용, 근거 주소
- **확인하지 못한 것** — 문서를 찾지 못했거나 문서에 설명이 없는 항목
- 차이가 없으면 "차이 없음"이라고 적는다.
