# 에이전트 설정 뼈대 만들기

템플릿은 특정 날짜의 공식 문서를 기준으로 만든 사본이다. 그대로 믿지 말고, 만든 뒤 커밋하기 전에 문서와 대조한다.

## 순서

1. **무엇을 만들지 정한다.** 이 스킬 폴더에서 `node scripts/scaffold.cjs --list` 로 쓸 수 있는 에이전트와 템플릿 기준일을 보고, 사용자에게 어떤 에이전트를 쓸지와 `.gitignore` 규칙을 넣을지 묻는다.
2. **만든다.** `node scripts/scaffold.cjs --dir <프로젝트 폴더> [--gitignore] <에이전트>...`
   - 공통 지침 파일은 어떤 에이전트를 골라도 만든다.
   - 이미 있는 파일은 덮어쓰지 않는다. `.gitignore` 는 있으면 끝에 블록을 덧붙이고, 다시 실행하면 그 블록만 갱신한다.
   - `--dry-run` 을 붙이면 만들지 않고 계획만 보여 준다.
3. **공식 문서와 대조한다.** 고른 에이전트마다 서브에이전트를 하나씩 병렬로 띄운다. 각 서브에이전트에게 스크립트가 출력한 파일 목록·설명·문서 주소·기준일을 넘기고, 그 에이전트의 현재 공식 문서를 읽어 다음을 보고하게 한다 — 없어지거나 이름이 바뀐 것, 형식이 달라진 것, 새로 권장되는 것. 근거 주소를 붙이게 한다.
4. **프로젝트에서 고친다.** 보고에 따라 생성된 파일을 프로젝트 안에서 고치거나 지운다. 설치된 플러그인의 템플릿은 고치지 않는다.
5. **커밋한다.** 저장소가 아니면 초기화하고, 공통 설정만 담아 첫 커밋을 만든다. 대조와 수정을 끝낸 뒤에 커밋해서 커밋을 고쳐 쓸 일이 없게 한다.
6. **템플릿이 낡았으면 알린다.** 3번에서 차이가 나왔으면 agent-template-update 스킬을 쓴다. 플러그인을 직접 고칠 수 있는 사용자는 템플릿을 고치고, 그 밖의 사용자는 이슈로 알린다.
