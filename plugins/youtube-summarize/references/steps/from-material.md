# 자료 직접 제공 모드 (from-material)

사용자가 영어 회화 패턴 자료를 직접 제공하면, 그 자료로 덱을 만든다. (영상 자막 분석 대신)

## 대화 흐름
1. 어떤 자료인지 확인하고, **영상 링크를 줄 수 있는지** 묻는다.
2. 링크 유무에 따라:
   - **링크 있음** → 오디오만 수집·트림해 **MP3 + PPT**
   - **링크 없음** → **PPT만**

## 파싱 규칙 (결정론적)
```
<영어 템플릿>: <뜻> (시간)     → header {primary:<템플릿>, secondary:<뜻>, t_seconds:<시간초>, label:<순번>}
<영어 문장> (<번역>)          → line   {primary:<문장>, secondary:<번역>}
```
- 덱 행 스키마·공통 규칙은 `references/types/english-conversation.md` 를 따른다.

## 덱 충실도
- 기본 = 제공 자료 **그대로**(명백한 오타/깨진 문장만 최소 교정).
- 사용자가 "예문 더 추가/정리해줘" 요청 시 → **보강·재정리**.

## 시간값 & 트림 (링크로 오디오 만들 때만)
- 자료 시간값은 기본 **원본 영상 기준**으로 해석.
- 트림 구간 = 첫 패턴 직전 ~ 마지막 패턴 직후 (자동). 필요하면 사용자에게 인트로/아웃트로 확인.
- 사용자가 "편집본에서 딴 시간"이라 하거나 정황상 의심되면 → **pre/post-trim 여부 확인 후** 정렬.
- **PPT만** 만들 땐 시간값은 슬라이드 배지로만(정렬 불필요).

## 산출
- 링크 있음: `analysis.json`(cut 포함)을 `.work/analysis.json` 에 쓰고 → `render <video-id>` (오디오는 링크에서 수집).
- 링크 없음: 오디오 없이 PPT만. (렌더 스크립트의 PPT-only 경로는 추후 지원 — 현재는 링크 있는 경우를 우선한다.)
