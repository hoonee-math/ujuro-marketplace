# A4 프린트 버전 (영어 예문 연습 인쇄물)

`render` 가 만든 `study.json` 을 근거로, 종이에 인쇄해 연습하기 좋은 **A4 세로** 덱을 만든다.
학습 슬라이드(`slides.pptx`)와 별개 산출물이며, 포맷(mode)별로 공존한다.

## 포맷(mode) — 계속 추가될 수 있다

| mode | 설명 | 상태 |
|------|------|------|
| `first` | 패턴별 **대표(첫) 예문 1문장**씩 한 줄로. 빨간 원형 번호 + 영어(볼드) `-` 한글 | 지원 |
| `all` | 패턴별 **모든 예문을 한 번호로 묶어** 출력. 배지는 묶음 세로 중앙에 하나. 예문 속 **패턴 고정어는 청색 볼드** 강조(시제 변화 퍼지 매치). 한 줄 유지(11.5/11pt) | 지원 |

- 사용자가 원하는 포맷이 불명확하면 **위 표를 근거로 질문**한다.
  (예: "패턴별 대표 예문 1개씩만 뽑을까요, 모든 예문을 번호별로 묶어 뽑을까요?")
- 아직 미지원 포맷을 원하면: 지원 예정이라 안내하고, 가능한 포맷을 제안한다.

## 실행

```bash
PYTHONPATH="${CLAUDE_PLUGIN_ROOT}/scripts" python -m pipeline.run render-a4 <video-id> --mode first
```

- `--max-per-page <줄수>` (기본 27): 페이지당 최대 줄 수. 페이지 높이 상한을 넘으면 자동으로 줄어든다.
- 페이지 채움: 앞 페이지부터 꽉 채우고 나머지는 마지막 페이지에. (번호 묶음은 페이지를 넘어 분할하지 않음)
- 산출물: `<workdir>/A4.<mode>.pptx` → `{"pptx_path","mode","n_items","n_lines","pages","per_page"}`
- 전제: `render` 가 먼저 실행되어 `.work/study.json` 이 있어야 한다.

## 새 포맷 추가 방법 (개발 메모)

1. `scripts/pipeline/build_a4.py` 의 `MODES` 에 추출기, `STYLES` 에 스타일 등록.
   추출기는 rows → items (`{"pattern": <템플릿|None>, "lines": [(영어, 한글), ...]}`
   = 원형 번호 하나로 묶이는 문장들)만 만들면 되고, 렌더링·페이지네이션은 공유된다.
2. 이 문서의 포맷 표에 한 줄 추가.
